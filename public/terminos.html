Términos y Condiciones

1. Propósito de la aplicación

Mi lista de tareas es una aplicación web desarrollada con fines educativos para administrar actividades personales en un entorno local.

2. Uso permitido

La aplicación permite registrar, consultar, actualizar y eliminar tareas. Su uso está destinado a actividades de aprendizaje y demostración.

3. Uso no permitido

No se permite utilizar la aplicación para actividades ilícitas, intentar vulnerar sus mecanismos de seguridad o introducir contenido que perjudique el funcionamiento del sistema.

4. Disponibilidad

Debido a que se trata de un proyecto académico en desarrollo, no se garantiza disponibilidad continua ni ausencia de errores.

5. Limitación de responsabilidad

La aplicación se proporciona como demostración educativa. No se recomienda utilizarla para almacenar información confidencial o crítica. En la medida permitida por la legislación aplicable, no se asume responsabilidad por pérdidas derivadas de fallas técnicas durante las pruebas del proyecto.

6. Modificaciones

Las características y condiciones de uso podrán modificarse como parte del desarrollo académico.
