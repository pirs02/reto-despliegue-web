Aviso de Privacidad

Aplicación: Mi lista de tareas

1. Información recopilada

Esta aplicación almacena los títulos, descripciones y estados de las tareas registradas por el usuario, así como sus fechas de creación. No solicita nombres, correos electrónicos ni otros datos personales de identificación.

2. Finalidad de la información

La información se utiliza exclusivamente para permitir el registro, consulta, actualización y eliminación de tareas.

3. Almacenamiento y protección

Los registros se almacenan en una base de datos PostgreSQL dentro de un entorno local de pruebas. La aplicación utiliza HTTPS, encabezados HTTP de seguridad y consultas SQL parametrizadas.

4. Compartición de información

La aplicación no incorpora funciones para compartir los registros con servicios externos.

5. Eliminación de información

El usuario puede eliminar sus tareas mediante las funciones disponibles en la aplicación.

6. Alcance del aviso

Este aviso se elaboró con fines académicos para una aplicación ejecutada en un entorno local de simulación.
